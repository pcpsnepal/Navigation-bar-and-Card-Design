# helloLearn

helloLearn is a simple online learning website designed to help students explore programming and web development courses.

## Features

- Professional navigation bar
- Six course cards
- Course images
- Responsive layout
- Hover effects
- About section
- Contact section
- Login section
- Footer

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Visual Studio Code

## Responsive Design

The website is responsive and adapts to different screen sizes:

- Desktop: 3 course cards per row
- Tablet: 2 course cards per row
- Mobile: 1 course card per row

## Why CSS Grid?

CSS Grid was chosen for the course card layout because it is suitable for arranging content in rows and columns. It also makes the responsive layout easier to manage.

## Project Structure

helloLearn/
│
├── images/
├── screenshots/
├── index.html
├── style.css
└── README.md

## How to Run

1. Open the project folder in Visual Studio Code.
2. Open `index.html`.
3. Run the website using Live Server.
